# 国际化

CrystalFramework 前端使用 `react-i18next` 实现国际化，支持按需动态加载语言文件。语言文件位于 `web/src/i18n/locales/`，文件名使用标准语言标签（如 `zh-CN.ts`、`en-US.ts`）。

## Key 结构

所有国际化 key 按功能划分为以下顶层命名空间：

| 命名空间 | 用途 | 示例 |
|---------|------|------|
| `pages` | 页面级别的文案 | `pages.userManager.title` |
| `components` | 组件级别的文案 | `components.dashboard.myJoinedTenants.title` |
| `entityNames` | 实体名称 | `entityNames.user` |
| `enums` | 枚举值翻译 | `enums.tenantMemberStatus.4` |
| `menu` | 侧边栏菜单 | `menu.admin.users` |
| `api` | API 通用消息 | `api.sessionExpired` |

## Key 命名规范

- 全部使用 **camelCase**
- 按层级从通用到具体排列：`{命名空间}.{模块}.{区域}.{具体字段}`
- **页面级别** key 以 `pages.{页面名}` 开头，适合页面标题、过滤条件标签、表单字段等
- **组件级别** key 以 `components.{组件名}` 开头，适合可复用组件的内部文案
- **列标题** 统一放在 `components.columns.{实体名}` 下
- 善用 **`{{variableName}}`** 插值替代字符串拼接，例如 `"共 {{total}} 条"`

## 如何添加

1. 在 `web/src/i18n/locales/{locale}.ts` 中添加翻译
2. 在组件中使用 `useTranslation()` 获取 `t` 函数

### 代码示例

```tsx
// locales/zh-CN.ts
pages: {
    myCustomPage: {
        title: '我的页面',
        subtitle: '这是我的自定义页面',
    },
    myCustomPage: {
        filter: {
            status: '状态',
            type: '类型',
        },
    },
},
components: {
    myComponent: {
        placeholder: '请输入...',
        confirmText: '确认',
    },
},

// 在页面组件中使用
import { useTranslation } from 'react-i18next';
import { ActionBarComponent } from '@/components/ActionBarComponent.tsx';

function MyPage() {
    const { t } = useTranslation();

    return (
        <ActionBarComponent
            title={t('pages.myCustomPage.title')}
            subtitle={t('pages.myCustomPage.subtitle')}
        />
    );
}
```

## 插值语法

语言文件中使用 `{{变量名}}` 作为占位符，`t()` 的第二个参数传入实际值：

```typescript
// 语言文件
{ "greeting": "你好，{{name}}！" }

// 组件中
t('greeting', { name: 'Alice' })
// 输出：你好，Alice！
```

## 枚举翻译

枚举值统一在 `enums` 命名空间下管理，必须严格执行以下四步流程，禁止在任何地方对枚举值使用硬编码标签。

### 第一步：定义前端枚举常量

后端定义的枚举必须在 `src/types/` 下有对应的 TypeScript 枚举。枚举值与后端字段保持一致：

```typescript
// src/types/tenant/tenant-benefit.types.ts
export enum TenantBenefitType {
    BOOLEAN = 0,
    LIMIT = 1,
    ENUM = 2,
}
```

::: warning 严禁魔法数字
所有组件和页面中必须使用枚举常量（如 `TenantBenefitType.BOOLEAN`）而非原始数字（`0`、`1`、`2`）。
:::

### 第二步：添加 i18n 翻译键

在 `src/i18n/locales/{locale}.ts` 的 `enums` 命名空间中添加翻译：

```typescript
// locales/zh-CN.ts
enums: {
    tenantBenefitType: {
        0: '开关',
        1: '数量限制',
        2: '枚举'
    },
}

// locales/en-US.ts
enums: {
    tenantBenefitType: {
        0: 'Boolean',
        1: 'Limit',
        2: 'Enum'
    },
}
```

### 第三步：注册获取函数

在 `src/i18n/enum-helpers.ts` 中注册获取函数，用于在组件中获取枚举值的翻译文本：

```typescript
// enum-helpers.ts
export function getTenantBenefitType(type: number): string {
    return translateEnum('tenantBenefitType', type);
}
```

### 第四步：在组件中使用

所有显示枚举值的地方必须通过获取函数获取翻译文本，禁止直接使用 `t('components.columns.xxx.typeBoolean')` 等分散的 i18n 键：

```tsx
import { TenantBenefitType } from "@/types/tenant/tenant-benefit.types.ts";
import { getTenantBenefitType } from "@/i18n/enum-helpers.ts";

// ✅ 正确：使用枚举常量 + 获取函数
<Select
    options={[
        { value: TenantBenefitType.BOOLEAN, label: getTenantBenefitType(TenantBenefitType.BOOLEAN) },
        { value: TenantBenefitType.LIMIT, label: getTenantBenefitType(TenantBenefitType.LIMIT) },
    ]}
/>

// ✅ 正确：表格列渲染
render: (_, row) => <Tag>{getTenantBenefitType(row.featureType)}</Tag>

// ❌ 错误：魔法数字 + 分散 i18n 键
render: (_, row) => {
    const map = { 0: t('...typeBoolean'), 1: t('...typeLimit') };
    return <Tag>{map[row.featureType]}</Tag>;
}
```

### 完整对照

| 步骤 | 文件 | 内容 |
|------|------|------|
| 1 | `src/types/{module}/{entity}.types.ts` | `export enum XxxType { ... }` |
| 2 | `src/i18n/locales/{locale}.ts` | `enums.xxxType: { 0: '...', 1: '...' }` |
| 3 | `src/i18n/enum-helpers.ts` | `export function getXxxType(...)` |
| 4 | 组件/页面中 | `getXxxType(XxxType.XXX)` |

## 系统设置 SDK：为自定义声明补 i18n

系统设置 / 租户设置管理页完全数据驱动：后端通过 `SystemSettingsRegistry` / `TenantSettingsRegistry` 动态声明设置项，前端 `SystemSettingsManagerPage` 按声明自动渲染控件。当外部模块通过 SDK 声明新的设置项（例如为自定义 `ResourceFileType` 注册可见性）时，只需要按下面 3 步补充前端 i18n，无需改任何页面代码。

### 前置：SDK 注册入口

前端插件通过 `@/plugin/registry.ts` 的 `pluginRegistry` 声明自身的 key / group / tab，注册后 `web/src/i18n/system-settings.tsx` 里的三个 Map 会自动兜底翻译。

```typescript
import { pluginRegistry } from '@/plugin/registry';

// 在插件的启动入口调用（一次即可）
pluginRegistry.addSettingsKey('system', 'resource.visibility.myFileType');
pluginRegistry.addSettingsGroup('system', 'resource.visibility'); // 已存在的 group 可以跳过
pluginRegistry.addSettingsTab('system', 'resource');              // 已存在的 tab 可以跳过
```

### 第一步：补 key 翻译

`pages.systemSettingsManager.keys.<key>` 用于设置项标签。key 使用点号分隔的层级路径，与后端 `SettingsItemDeclaration.key` 完全一致。

```typescript
// locales/zh-CN.ts
pages: {
    systemSettingsManager: {
        keys: {
            'resource.visibility.myFileType': '我的自定义文件类型可见性',
        },
    },
},
```

### 第二步：如果是新 group / 新 tab，补对应翻译

`pages.systemSettingsManager.groups.<group>` 和 `pages.systemSettingsManager.tabs.<tab>` 用于分组/页签名称。若沿用已有 group（如 `resource.visibility`）和 tab（如 `resource`），跳过本步。

```typescript
// locales/zh-CN.ts
pages: {
    systemSettingsManager: {
        groups: {
            'myModule.mySection': '我的分组',
        },
        tabs: {
            'myModule': '我的页签',
        },
    },
},
```

### 第三步：如果声明是枚举类型（`ENUM_SINGLE` / `ENUM_MULTIPLE`），补每个枚举值的翻译

管理页通过 `pages.systemSettingsManager.enums.<settingsKey>.<enumValue>` 翻译每个下拉项。**注意 `settingsKey` 是完整的设置项 key，不是枚举类型名** —— 即使多个设置项共用同一个后端枚举，也必须为每个 key 各写一份枚举翻译块（与现有内置声明的做法一致，见 `resource.visibility.userAvatar` / `resource.visibility.tenantIcon` 等）。

```typescript
// locales/zh-CN.ts
pages: {
    systemSettingsManager: {
        enums: {
            'resource.visibility.myFileType': {
                'PUBLIC': '公开（任何人可访问）',
                'AUTHENTICATED': '已登录用户',
                'SCOPE_MEMBER': '同租户成员',
                'OWNER_ONLY': '仅上传者本人',
                'SYSTEM_ADMIN': '仅系统管理员',
            },
        },
    },
},
```

### 完整对照

| 步骤 | 文件 | 内容 |
|------|------|------|
| 0 | 插件启动入口 | `pluginRegistry.addSettingsKey('system', '<key>')` |
| 1 | `src/i18n/locales/{locale}.ts` | `pages.systemSettingsManager.keys.<key>: '...'` |
| 2（可选） | `src/i18n/locales/{locale}.ts` | `pages.systemSettingsManager.groups.<group>: '...'` / `tabs.<tab>: '...'` |
| 3（枚举类型） | `src/i18n/locales/{locale}.ts` | `pages.systemSettingsManager.enums.<key>: { <enumValue>: '...' }` |

::: tip 无需改页面
上述改动完成后，`SystemSettingsManagerPage` 会自动在 `resource` 页签 → `resource.visibility` 分组下显示新的设置项，无需修改任何 tsx 页面/组件文件。
:::

::: warning 跨语言同步
`docs/develop/frontend/i18n.md` 与 `docs/en/develop/frontend/i18n.md` 必须同步更新；`web/src/i18n/locales/zh-CN.ts` 与 `en-US.ts` 也必须条目数一一对应。
:::
